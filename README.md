# Public Company Research

Source files for the public company research library. The ERGO brief covers publicly documented products, markets, ownership, and customer and employee feedback.

- [Report directory](docs/reports)
- [JSON Schema for the embedded report data](docs/schemas/company-report-v1.schema.json)

The schema uses JSON Schema Draft 2020-12. It describes the JSON object in the HTML's `company-report-data` script. This repository contains public research exports.
